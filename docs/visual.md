# 見た目の判断

## 出発点(2026-10-22)

雛形(2026-10-16)のスタイルを見た本人の指摘(原文):

> 全体的に余白の使い方がキモい。グルーピングの原則を思い出して。色使いもかっこよくない。ぼんやりとしていて、インパクトに欠ける。もう少し色々試してみて。astraやsolにもみてもらって意見をもらって。最終的に3-6案くらいに絞って私に見せて

雛形の状態: 背景 #121212、本文 #e6e6e3、薄い文字 #8c8c88。節間が一律 7rem、節内が一律 1〜1.5rem で、まとまりが目で分からない。写真以外に色が無く、全体が中間調。

## 案の比較の仕組み

- `src/styles/variants/<name>.css` に1案1ファイル。すべてのセレクタを `html[data-v="<name>"]` で始める(Astro のスコープ付きスタイルより詳細度が高くなる)。
- 開発サーバーで `?v=<name>` を付けると `<html data-v="<name>">` が付き、その案で表示される。sessionStorage に残るのでページを移っても保たれる。`?v=` (空)で戻す。
- 案が決まったら global.css と各コンポーネントに畳み込み、`variants/` と切り替えの仕組みを消す。

## 第1回の候補は棄却(2026-10-22)

余白と色の調整だけの5案(tight / display / ledger / sheet / paper。astra の診断と sol の2案を含む)を見せたところ、本人の判定:

> 全部しょぼすぎる。HTML+CSSの初心者が最初に作るサイトみたい。funomiのモックサイトとか見て、あれくらいのクオリティにはしてよ

品質の基準は funomi のモック(`mf/product-sales/mock`、`docs/shop-mocks.md`)。モックの語彙: 等幅 13px を基本にして日本語の文だけ `.ja`、区画は上の罫線と左の節名列(200px)、図は枠と「図 01」の番号と年の行、仕様は罫線の表、一覧は番号付きの行、末尾は名前と連絡先。CSS の値はモックの `base.css` / `dirs.css` から取った。

## 第2回の候補(2026-10-22)

マークアップから作り直した(`global.css` が既定の「標本」、`variants/` の3案はトークンと一部の配置を差し替える)。ページ構成は変えていない。

| 案 | モックの対応 | 中身 | 色 |
|---|---|---|---|
| specimen(標本、既定) | A / G | 紙色地。罫線と左の節名列、作品は番号付きの枠の図、経歴は罫線の行 | #f4f4f2 / #1a1a1b / #6b6b68 |
| terminal(端末) | C | 墨地、全面等幅。名前を等幅の大きなワードマークに、節名は「# 」付き、図は枠なし | #1a1a1b / #f4f4f2 / #9a9a96 |
| ledger(台帳) | E | グレー地、墨の実線の箱。作品も経歴も箱に入れ、文字は 14 / 18 / 28 / 56 | #d8d8d8 / #1a1a1b の2色 |
| gallery(余白) | B | 紙色地、罫線なし。導入は中央、最初の作品を幅いっぱいに、残りは2列 | #f4f4f2 / #1a1a1b / #6b6b68 |
