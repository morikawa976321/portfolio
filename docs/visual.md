# 見た目の判断

## 出発点(2026-10-22)

雛形(2026-10-16)のスタイルを見た本人の指摘(原文):

> 全体的に余白の使い方がキモい。グルーピングの原則を思い出して。色使いもかっこよくない。ぼんやりとしていて、インパクトに欠ける。もう少し色々試してみて。astraやsolにもみてもらって意見をもらって。最終的に3-6案くらいに絞って私に見せて

雛形の状態: 背景 #121212、本文 #e6e6e3、薄い文字 #8c8c88。節間が一律 7rem、節内が一律 1〜1.5rem で、まとまりが目で分からない。写真以外に色が無く、全体が中間調。

## 案の比較の仕組み

- `src/styles/variants/<name>.css` に1案1ファイル。すべてのセレクタを `html[data-v="<name>"]` で始める(Astro のスコープ付きスタイルより詳細度が高くなる)。
- 開発サーバーで `?v=<name>` を付けると `<html data-v="<name>">` が付き、その案で表示される。sessionStorage に残るのでページを移っても保たれる。`?v=` (空)で戻す。
- 案が決まったら global.css と各コンポーネントに畳み込み、`variants/` と切り替えの仕組みを消す。

## 第2回も棄却(2026-10-23)

仕様書の組版の4案(specimen / terminal / ledger / gallery)への本人の判定:

> いや、なんか、もっとモダンなデザインにできない？ なにがいけないのだろう。まだショボさがあるのだ。

AI(Claude)の診断(本人は未確認):
1. 写真が最大の要因。手持ちのスナップ(机の上・白い壁・暗所)で色味も構図もばらばらなので、小さな枠に並べるほど「寄せ集め」に見える。設計で緩和するには、同じ比率に揃えて大きく出し、角を丸めて面として扱う。根本は撮り直し。
2. 文字の段が小さい。等幅 13px を基本にした仕様書の組版は製品の台帳には合うが、人のサイトでは「文書」に見える。現代の個人サイトは最初の画面を大きな名前か一文で作り、本文は 16px 以上。
3. 最初の画面に焦点が無い。名前・所属の後にすぐ格子が始まり、導入の一行(headline)も空のまま。
4. 罫線の枠が多いと線画(ワイヤーフレーム)に見える。線は経歴の行だけにし、文字色の 10% まで薄くする。
5. 角が全部直角で、ホバーや現れ方の動きも無い。写真は角を丸め、ホバーでわずかに拡大し、最初の画面は下から現れる。

## 配色から決める(2026-10-24)

本人の提案「まず配色から決めるというのはどうでしょう」。第5回の形(night)に配色だけを差し替えた6候補を同じ画面に当てて比べた(`?v=charcoal` 等。既定は ink)。

| 候補 | 地 / 文字 | 文字:地 | 薄い文字:地 | 出どころ |
|---|---|---|---|---|
| ink(墨) | #0b0b0c / #f2f2f0 | 17.6:1 | 6.6:1 | 第3回以降の既定。新しい値 |
| charcoal(炭) | #1a1a1b / #f4f4f2 | 15.8:1 | 6.4:1 | design-system のロゴの2色を反転(モック C と同じ) |
| paper(紙) | #f4f4f2 / #1a1a1b | 15.8:1 | 4.4:1 | design-system のロゴの2色そのまま。モック A/G と仮スキンの値 |
| white(白) | #ffffff / #111111 | 18.9:1 | 5.0:1 | takram / goshiuhira。新しい値 |
| gray(灰) | #d8d8d8 / #1a1a1b | 12.2:1 | 4.3:1 | モック E/H とスライドの既定 RGB216 |
| ink-accent | ink + リンクに #ff4d00 | 橙:地 5.9:1 | — | アクセントを入れるか自体を見る仮色 |

design-system と product-sales から取った事実(AI の抽出、2026-10-24):
- ブランド層は無彩色・最大3色、アクセントは未決。原則5「色彩の判断はトータルコーディネートの層(サイト・梱包・写真)で一度だけ行う」。D3 でポートフォリオはこの層に入る。
- 既に値が決まっている色は、ロゴの2色 #1a1a1b(墨)と #f4f4f2(紙)だけ。ロゴ PNG は紙地に墨、または反転の2種で、透明地をやめた理由は「暗い背景のUIで墨の印が消える」。
- ショップの仮スキンは #f4f4f2 / #1a1a1b / #6b6b68。モックの既定の地も #f4f4f2。ダーク/ライトの方針も、ショップの方向(A〜H)の選定も記述なし。
- 製品写真は未着手。参照情報(AI まとめ)では白い紙の背景・自然光。

この事実から、新しい値を増やさずに済む候補は charcoal と paper の2つ(同じ2色の反転)。ink・white・gray は値を増やす。アクセントは設計システム側で未決なので、ここで入れるとブランド層の決定になる。

AI(Claude)の判断材料(本人未確認): 製品写真を白い紙の背景で撮る計画なら、紙地のほうが写真が沈まず、墨地では白い長方形が並ぶ。ロゴも紙地に墨が正。一方で本人は UI にダークテーマを好むと述べてきた。

本人の判定(2026-10-24、極端な色の閾値実験 `mf/design-system/specimens/extreme-color-threshold.html` の後):

> 実際にink,paperのモックは許容できない。charcoal,grayは全然平気。

背景に使う極端な色の線(本人の原則「#000・#fff のような極端な色は、背景など面積を大きく占める場所には使わない」)をこの実験で測り、AI が PC の結果から黒 L 0.21 以上・白 L 0.89 以下(灰なら 25〜218)を案として出した段階。ink(11)と paper(244)はこの案の外、charcoal(26)と gray(216)は内側で、本人の判定と一致する。線は同日に本人が灰の値 20〜224 と決めた(背景など面積の大きい場所に当てる指針で、制約ではない。正は `mf/design-system/worldview.md` の「大きな面の明るさ」)。この範囲でも ink と paper は外、charcoal と gray は内側。

全案に共通して当てたもの:
- 本人の5つの基準。動き(transition / animation)を書かない。リンクは下線か矢印。罫線を使わず、余白の段(4〜160)で近いものほど詰める。作品と経歴の間を最大に、経歴・研究・受賞の間はそれより狭くして3つを1群に見せる。
- 構成は structure.md のまま。nav なし、名前がトップへのリンク、連絡先は末尾に1つ、作品一覧への導線はトップの「すべての作品 →」と作品詳細末尾の「← すべての作品」だけ。作品数は出さない。
- 書体は Intel One Mono(年・期間・英名)と Noto Sans JP。短い日本語の行は `word-break: auto-phrase` で文節で折り返す(Chrome 119+)。

中身:
- 確定済みの値: 名前、所属、トップの6件と全16件の題、経歴・研究・受賞(src/data/profile.ts の値。インターンの期間は未記入なので 20XX.XX)。
